## 一、软件概述

### 1.1 软件简介

"电满满"是一款面向新能源汽车车主的智能充电导航综合服务平台。软件通过融合高德地图实时路况数据、充电运营商运营数据、开源路网数据与本地车型参数数据库，为用户提供充电站智能推荐、路径规划导航、实时充电桩状态查询、充电费用估算、收藏与历史记录管理等一站式服务。同时为平台管理员提供用户管理、数据统计分析与站内公告发布等后台管理功能。

### 1.2 软件组成

本软件由两个客户端和一个后端服务组成：

| 组成部分 | 技术架构 | 运行环境 |
|----------|----------|----------|
| 移动端 App | Flutter + Dart | Android 8.0+ |
| 管理后台 | Flutter Web | Chrome / Edge 浏览器 |
| 后端服务 | Python FastAPI + SQLite | Linux / Windows 服务器 |

### 1.3 核心功能

1. 充电站智能推荐与路径规划导航
2. 充电站详情查看与收藏管理
3. 用户充电历史记录管理
4. 车辆型号配置与充电参数自动匹配
5. 平台公告推送与展示
6. 管理后台（用户管理、数据统计、公告管理、电站总览）

## 二、移动端 App 功能说明

### 2.1 用户注册与登录

**功能描述**：用户可通过手机号/用户名注册账号并登录系统。软件支持游客模式，未登录用户可使用全部核心功能，登录后实现数据云端同步。

**操作流程**：
1. 首次使用点击"注册"，填写用户名（3-50位）、密码（6-128位）、昵称和手机号
2. 注册成功后自动登录，跳转至主页
3. 已注册用户直接输入用户名和密码登录
4. 登录状态保持 7 天，过期自动续期

> 【截图位置：登录页、注册页各一张】

---

### 2.2 首页地图与充电站推荐

**功能描述**：软件首页展示高德地图图层及用户当前位置。系统根据用户当前电量、车型参数、位置坐标，智能推荐附近最优充电站，以卡片轮播形式展示推荐结果，同时在地图上标注各充电站位置。

**主要功能**：
- 地图实时显示用户位置及周边充电站标记
- 底部推荐卡片展示充电站名称、类型、距离、可用桩数、电价
- 滑动卡片时地图自动移动到对应充电站位置
- 点击地图标记可快速定位到对应推荐卡片
- 首页顶部展示平台最新公告滚动条
- 支持"定位到我的位置"一键回中
- 车辆与电量调节按钮，实时重新测算推荐结果

**推荐算法**：采用多目标加权评分模型，综合距离、电价、等待时间、充电功率四维因素，结合用户车型的电池容量和能耗参数，筛选可达范围内的充电站并排序推荐。

> 【截图位置：首页地图全貌、推荐卡片展开、公告滚动条各一张】

---

### 2.3 充电站详情与导航

**功能描述**：点击任意充电站可进入详情页面，查看充电站的完整信息并提供一键导航功能。

**详情页内容**：
- 充电站名称、类型标签、推荐语
- 距离、预估充电时间、预估费用
- 最大充电功率、可用桩数/总桩数、预计等待时间
- 充电站地址文字与地图预览
- 电价信息（电费/服务费/停车费）
- 营业时间、联系电话

**操作按钮**：
- **立即导航**：跳转至高德地图导航页面，显示从当前位置到充电站的驾车路线
- **联系站点**：一键拨打充电站联系电话
- **收藏站点**：点击星标按钮添加/取消收藏

> 【截图位置：详情页全貌、导航页面各一张】

---

### 2.4 收藏站点管理

**功能描述**：用户可将常去的充电站添加至收藏列表，方便快速访问。收藏页面展示每个站点的类型、可用桩数和电价信息，点击即可进入详情页。

**操作流程**：
1. 在充电站详情页点击星标即可收藏
2. 进入"我的"→"收藏站点"查看所有收藏
3. 点击任意收藏站点进入详情页
4. 在详情页再次点击星标取消收藏
5. 登录后收藏数据自动同步至云端

> 【截图位置：收藏站点列表页一张】

---

### 2.5 历史记录管理

**功能描述**：系统自动记录用户访问过的充电站，按时间倒序排列。用户可查看历史记录、点击进入充电站详情，并支持批量删除不需要的记录。

**操作流程**：
1. 点击推荐站点进入详情页，系统自动记录访问历史
2. 进入"我的"→"历史记录"查看完整列表
3. 每条记录显示站点名称、类型图标和访问时间
4. 点击右上角删除图标进入选择模式，可多选删除
5. 登录后历史数据自动同步至云端

> 【截图位置：历史记录列表页、批量删除状态各一张】

---

### 2.6 车辆与电量配置

**功能描述**：软件内置 15 个品牌、60 余款主流电动车型的参数数据库。用户可选择自己的车型及当前电量，系统自动匹配电池容量、能耗率、最大充电功率，并据此进行充电站推荐与续航计算。

**操作流程**：
1. 点击首页"车辆与电量"按钮弹出配置面板
2. 横向滑动选择品牌（特斯拉/比亚迪/蔚来/小鹏等 15 个品牌）
3. 点击选择具体车型，系统自动填充电池容量和能耗参数
4. 拖动 SOC 滑块设置当前电量百分比（0-100%）
5. 点击"应用并重新测算"，系统使用新参数重新推荐充电站

> 【截图位置：车辆配置面板一张】

---

### 2.7 个人中心

**功能描述**：个人中心展示用户基本信息、车型与电量状态，提供历史记录、收藏站点、设置等功能的入口，以及登录/退出操作。

**主要入口**：
- 用户头像与昵称展示
- 当前车型、SOC 电量显示
- 历史记录入口
- 收藏站点入口
- 系统设置入口
- 退出登录按钮

## 三、管理后台功能说明

### 3.1 管理员登录

**功能描述**：管理员通过专用账号和密码登录后台管理系统。系统区分普通管理员（admin）和超级管理员（super_admin）两种角色，不同角色拥有不同的功能权限。

> 【截图位置：管理后台登录页一张】

---

### 3.2 Dashboard 仪表盘

**功能描述**：登录后首页展示平台关键数据统计，包括用户总数、车辆总数、收藏总数、充电记录数，以及用户增长趋势折线图、充电时段分布柱状图、车辆品牌分布饼图、热门站点排名等。

> 【截图位置：Dashboard 页面一张】

---

### 3.3 用户管理

**功能描述**：管理员可查看平台所有注册用户列表，支持按用户名和手机号搜索，查看用户的车辆列表和充电记录，以及删除违规用户。

> 【截图位置：用户管理页面一张】

---

### 3.4 站内公告管理

**功能描述**：管理员可创建、编辑、发布和删除平台公告。已发布的公告将在移动端 App 首页以滚动横幅形式展示给所有用户。

> 【截图位置：公告管理页面一张】

---

### 3.5 充电站数据总览

**功能描述**：管理员可查看平台覆盖的所有充电站数据，支持按区域、类型筛选和关键字搜索，点击可查看充电站详细信息。

> 【截图位置：电站总览页面一张】

## 四、技术参数

| 项目 | 参数 |
|------|------|
| 后端框架 | FastAPI (Python 3.11) |
| 前端框架 | Flutter 3.x (Dart) |
| 数据库 | SQLite 3 |
| 地图服务 | 高德地图 API |
| 路网数据 | OpenStreetMap (OSM) |
| 认证方式 | JWT (HS256) |
| 推荐算法 | 多目标加权评分 (MCDA) |
| 路径规划 | A* 搜索算法 + 高德驾车导航 |
| 充电模型 | 分段线性充电曲线拟合 |
| 充电站数量 | 武汉市 152 座充电站 / 982 个充电桩 |
| 车型数据库 | 15 品牌 / 60+ 款车型 |
